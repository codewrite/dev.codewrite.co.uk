I've put the UPS in a case. I was going to 3D print a case, but that's a lot of plastic, so I just put it in a generic plastic container:

![HA UPS Mk2 Block Diagram](/images/HA-UPS-mk2/HAUPS-PlasticCaseTop.jpg)

The lid keeps the dust out, inside I have put bits of cardboard in to keep things apart.

![HA UPS Mk2 Block Diagram](/images/HA-UPS-mk2/HAUPS-PlasticCaseTopOpen.jpg)

I'm not going to close the lid so that there is some airflow - not that it needs much - but it might if it gets hot again next summer.

![HA UPS Mk2 Block Diagram](/images/HA-UPS-mk2/HAUPS-PlasticCaseSide.jpg)

One day I might design a case, but for now that'll do. Once I've finished testing this is going to sit on top of a bookcase with my "real" home assistant server in an Argon One case (the one shown here is the test server in a Argon Neo case).
